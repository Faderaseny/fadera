Programmer en français.

Fadéra est un langage de programmation dont les mots-clés, les messages d'erreur et la documentation sont en français. Pour apprendre la logique sans passer par l'anglais, et pour écrire de vrais outils : traitement de données, automatisation, contrôle qualité. Libre et gratuit.

Rien à installer pour essayer : l'éditeur tourne dans le navigateur.

exemple.fa
soit prenom = "Fatima"
soit note = 15

si note >= 10 alors
    afficher prenom + " est admise !"
sinon
    afficher prenom + " doit réviser."
fin

pour i allantde 1 a 3 faire
    afficher "Essai " + i
fin
Résultat
Fatima est admise !
Essai 1
Essai 2
Essai 3

Un langage qui parle la langue de la classe

Les débutants butent autant sur l'anglais que sur la logique. Fadéra enlève la première difficulté.

Mots-clés

Du français partout

soit, si … alors … sinon, pour … allantde … faire, tantque, fonction, renvoyer. Ce qui s'écrit se lit comme une phrase.

Erreurs

Des messages qui expliquent

Une variable mal écrite ? Fadéra le dit en français, donne la ligne et indique comment la déclarer.

Fiabilité

Deux moteurs, un même résultat

Un moteur JavaScript dans le navigateur et un moteur Rust en ligne de commande. Des centaines de programmes de test vérifient qu'ils répondent à l'identique.

erreur.fa
soit prenom = "Fatima"
afficher prenon
Résultat
Erreur : Ligne 2 : La variable "prenon" n'existe pas.
Déclarez-la d'abord avec : soit prenon = ...
fonction.fa
fonction carre(x)
    renvoyer x * x
fin

afficher "Le carré de 7 est " + carre(7)
Résultat
Le carré de 7 est 49

Pas seulement pour enseigner

Fadéra est né dans les classes, mais il sert aussi à travailler : le même langage, du premier afficher jusqu'aux outils d'atelier et de bureau.

Données

CSV, JSON, fichiers, journaux

Lire, nettoyer et résumer des données, statistiques comprises, puis écrire un rapport ou un fichier de résultats.

Automatisation

Des scripts en ligne de commande

Le moteur Rust lance un programme .fa comme n'importe quel outil, sous Windows, avec ses terminaux PowerShell et cmd intégrés.

Métiers

Industrie, finance, santé, télécoms

Contrôle qualité, surveillance d'une machine, facturation, indicateurs de santé : des exercices corrigés montrent ces usages.

Qualité

Des programmes qu'on peut tester

Tests intégrés au langage, formateur de code, paquets partageables, chiffrement et signature HMAC pour protéger ses échanges.

Quatre façons de l'utiliser

Choisissez selon la salle : de zéro installation à l'environnement complet.

En ligneL'éditeur, le terminal et le moteur dans le navigateur. Aucun compte, aucun téléchargement. Idéal pour une salle sans droits d'installation.Ouvrir →
Fadéra IDE (Windows)L'installateur pose l'éditeur dans sa fenêtre, les raccourcis, l'ouverture des fichiers .fa par double-clic, et un vrai terminal PowerShell ou cmd intégré.Télécharger →
Ligne de commandeLe moteur fadera pour Windows, Linux et macOS : fadera run programme.fa, un testeur, un formateur, un débogueur et un gestionnaire de paquets.Archives →
Hors ligneLe playground se télécharge en un seul dossier : ouvrez index.html dans un navigateur, sans internet.Playground →

Windows ou un antivirus peut afficher un avertissement : le programme est jeune et pas encore signé numériquement. La marche à suivre est dans le guide (section 27).
